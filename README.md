Proyecto Servidor Linux automatizado con Docker
El proyecto consiste en la implementación y configuración de un servidor Linux automatizado. Integra prácticas de administración de sistemas (gestión de usuarios, grupos y permisos), 
automatización de tareas mediante Bash y Cron, control de versiones con Git/GitHub, y virtualización de servicios utilizando contenedores y redes en Docker.
